Iris Flower Classification 

Overview

This project uses machine learning to classify Iris flowers into three species: Setosa, Versicolor, and Virginica, based on their physical measurements.

Technologies Used

* Python
* Scikit-learn
* Machine Learning
* Random Forest Classifier

Dataset

The project uses the Iris dataset available through Scikit-learn.

The dataset contains 150 flower samples, each described by four features:

* Sepal length
* Sepal width
* Petal length
* Petal width

Methodology

1. Loaded the Iris dataset.
2. Split the data into training and testing sets using an 80:20 ratio.
3. Trained a Random Forest classification model.
4. Generated predictions for the test data.
5. Evaluated the model using accuracy, a classification report, and a confusion matrix.
6. Tested the model on a new flower sample.

Sample Prediction

The model predicts the species of a flower from its four measurements.

* Training a classification model.
* Making predictions with Scikit-learn.
* Evaluating a machine learning model.
